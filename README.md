# AutoChat (Fabric 1.21.4, клиентский мод)

Меню: **Right Shift** (клавишу можно сменить в Управление → AutoChat).

## Возможности
- **Сообщения** — любое число записей: текст, задержка в секундах (можно 0.5), «Цикл» / «1 раз».
  Если текст начинается с `/`, он отправляется как команда.
- **Автоответ** — триггер + ответ, режим (Содержит / Точно / Начало / Regex), задержка ответа.
  В ответе работают `{player}` и `{msg}`. Ответ с `/` — команда.
- **Анти-АФК** — прыжок, поворот головы, ходьба вперёд-назад, взмах рукой; интервал ±10%.
- **Настройки** — автоответ вкл/выкл, кулдаун, игнор своих сообщений, HUD.
- Главный выключатель «Мод» вверху справа, а также отдельная клавиша (по умолчанию не назначена).
- Конфиг: `config/autochat.json`.

## Сборка
Нужны JDK 21 и интернет.
```
gradle wrapper --gradle-version 8.12   # один раз, если нет gradlew
./gradlew build                        # jar будет в build/libs/autochat-1.0.0.jar
```
Либо откройте папку в IntelliJ IDEA — она сама настроит Gradle.
Положите jar в `mods` вместе с Fabric API для 1.21.4.
